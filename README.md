# Venkatesh — Senior iOS Developer Portfolio

This is a beginner-friendly static portfolio website built with HTML and CSS.

## Files
- `index.html` — website content
- `styles.css` — visual design and responsive layout

## Before publishing
1. Review every line of content for accuracy.
2. Replace the generic GitHub and LinkedIn URLs with your own profiles.
3. Decide whether to display your email address publicly.
4. Only add a resume PDF if you are comfortable publishing the personal contact information inside it.
5. Confirm you are permitted to describe each company project. Do not publish private source code, customer information, or confidential screenshots.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your exact GitHub username).
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment. Your site should appear at `https://YOUR-USERNAME.github.io/`.

If you use a differently named repository, the URL and configuration will differ.

## Updating the site
Edit `index.html` or `styles.css` in GitHub using the pencil/edit button, then commit the changes. GitHub Pages will redeploy automatically.

## Notes
- This site uses a Google Fonts import; system fonts remain as fallback if the font service is unavailable.
- Project descriptions are high-level summaries based on the supplied resume. Add approved screenshots, App Store links, and code samples only when permitted.
